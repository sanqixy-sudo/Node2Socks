# Node2Socks UI 重构与绿色版复核 — 2026-08-26

## 本次重构

- 新增固定 38px 自绘顶栏、紧凑侧栏、浅色/深色/跟随系统主题与手动折叠。
- 根窗口禁止滚动，只有主内容画布滚动且隐藏系统滚动条。
- 概览、订阅、节点、Proxy Slot、云同步、设置与诊断全部改为紧凑桌面布局。
- 订阅高级编辑、批量 Slot、类型化设置、数据库恢复和系统文件对话框均接入真实 Rust 命令。
- 侧栏不重复显示应用品牌；改变窗口大小不会自动隐藏导航文字或底部 Core 状态。
- Proxy Slot 默认复制 AdsPower 格式并附带节点/自定义槽位名称备注；支持重命名和三种导出格式，刷新 URL 明确留空。

## 后端与安全

- 端口范围和删除冷却从持久化设置读取；批量创建、删除使用 SQLite 事务。
- 节点消失继续 fail-closed，固定端口冲突不会自动改号。
- 主题、密度、端口范围和冷却设置加入端到端加密云同步；设备网卡和托盘选项保持本机设置。
- 数据库恢复前自动停止 Core、创建恢复前备份并校验数据库。
