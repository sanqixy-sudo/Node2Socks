# 08 — UI / UX 结构

UI 完全自己做，不复刻 Clash Verge。

## 风格

- Windows 桌面现代、干净、信息密度中等。
- 左侧导航 + 内容区。
- 主色不硬编码到业务；支持 light/dark 后期再做。
- 状态用文字 + icon，不仅靠颜色。

## 首页

卡片：

- Core：运行/停止、版本。
- Slots：总数/正常/阻断/端口冲突。
- Nodes：总数/可用/异常。
- Subscriptions：数量/最近刷新。
- Cloud：本地模式或已同步。
- Clash：未检测/System Proxy/疑似 TUN。

快捷操作：添加订阅、批量创建 Slot、复制全部 SOCKS、运行诊断。

## 订阅页

表格：名称、URL（脱敏）、节点数、上次成功、下次刷新、状态。

详情：刷新周期、下载网络模式（直连/系统代理/自定义 HTTP/SOCKS5 代理/通过节点下载）、headers、缓存、立即刷新。选择「通过节点下载」时需指定一个存活节点，下载经本机 Core 从该节点拨号。

## 节点页

列：节点名、订阅、协议、国家/标签、延迟、出口 IP、Slot。

操作：测速、测出口、创建 Slot、绑定到已有 Slot。

## Slot 页（核心页面）

```text
21001   JP Tokyo 01      VLESS   82ms   ● 正常      [复制] [切换]
21002   US LA 03         Trojan  145ms  ● 正常      [复制] [切换]
21003   JP Tokyo Old     VLESS   --      ● 已失效    [替换节点]
21004   --               --      --      ○ 未绑定    [选择节点]
```

支持：

- 搜索端口/备注/节点。
- 批量导出。
- 批量新建（选 N 个节点自动从端口池分配）。
- 删除 Slot 二次确认。

## 云同步页

未启用：突出“本地模式正在使用”，云是可选。

已启用：服务器地址、账号、设备、最后同步、pending count、冲突。

## 错误文案

端口冲突要明确：

```text
端口 21001 当前被 chrome.exe / PID 1234 占用。
Node2Socks 不会自动修改这个已同步端口。
```

节点失效：

```text
该 Slot 的上游节点已从订阅中消失。为避免意外换 IP，Slot 已阻断。
```
