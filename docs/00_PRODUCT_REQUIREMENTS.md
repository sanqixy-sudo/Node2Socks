# 00 — 产品需求文档（PRD）

## 1. 产品定位

Node2Socks 是本地代理协议适配与稳定端口管理工具，不是系统 VPN 客户端，也不是新的 Clash GUI。它解决的问题是：机场节点通常是 VLESS / VMess / Trojan / SS / Hysteria2 / TUIC 等协议，而 AdsPower、浏览器、自动化工具通常只接受 HTTP/SOCKS5。Node2Socks 自己连接上游节点，并给每个代理槽位暴露稳定的本地 SOCKS5。

## 2. 核心用户场景

1. 用户 Windows 本机用 Clash 做日常网络。
2. 用户在 Node2Socks 添加一条或多条机场订阅。
3. 软件解析/加载节点并显示状态。
4. 用户选 JP-01 创建 Slot，得到 `127.0.0.1:21001`。
5. 用户选 US-03 创建 Slot，得到 `127.0.0.1:21002`。
6. AdsPower 环境分别填入对应 SOCKS5。
7. 机场订阅刷新时，端口不改变。
8. 节点失效时，Slot 保留，用户选择新节点“继承端口”。
9. 用户重装软件后，若已启用云同步，只需安装、输入自建云域名并登录，恢复订阅、缓存节点、Slot、端口映射和设置。

## 3. 必须支持

### 3.1 本地功能

- Windows 10/11 x64。
- 无账号本地模式。
- 添加订阅 URL；可自定义名称、刷新周期、User-Agent/Headers（高级）。
- 支持常见订阅内容：Clash YAML / proxy-provider YAML、URI 文本、Base64 URI 列表。
- v1 重点协议：VLESS（含 Reality）、VMess、Trojan、Shadowsocks、Hysteria2、TUIC、HTTP、SOCKS5。实际协议解析/拨号交给 Mihomo。
- 节点列表、搜索、订阅筛选、协议筛选、延迟测试、出口 IP 测试。
- Proxy Slot：固定本地端口、绑定节点、解绑、替换节点、复制 SOCKS5。
- 批量创建 Slot；默认端口范围 21000–21999，可配置。
- 批量导出：`socks5://127.0.0.1:21001` 一行一个；以及 `127.0.0.1:21001` 格式。
- 自动订阅刷新。
- Core 自动启动、崩溃重启、优雅退出。
- 托盘、开机启动可选。
- 日志和诊断包（自动脱敏）。

### 3.2 稳定性约束

- Slot 端口重启后不变。
- 云同步恢复后端口不变。
- 端口被其他程序占用时显示冲突，禁止静默换端口。
- 绑定节点失效/消失时 fail-closed：连接失败，不允许自动换到其他活节点。
- 订阅更新不得把 Slot 绑定关系随节点排序改变。

### 3.3 云同步

- 完全可选。
- 用户手工输入云服务器 Base URL。
- 云服务器由用户自己 Docker 部署。
- 用户自己反代 HTTPS 域名。
- 支持注册、登录、设备列表、注销设备。
- 同步：订阅、订阅缓存、节点目录元数据、Slot、端口、绑定、标签、用户设置。
- 不同步：实时流量、连接记录、延迟瞬时值、本地日志。
- 离线优先，云不可用不影响本地代理。
- 变更队列恢复联网后自动同步。
- 云服务器只保存配置，不转发代理流量。

## 4. 本机 Clash 共存

Node2Socks 与 Clash：

- 不共享进程。
- 不共享配置目录。
- 不共享 Controller。
- 不共享监听端口。
- Node2Socks 代理核心不读取 Windows 系统 HTTP Proxy。

Clash 仅开启 System Proxy 时，两者天然独立。Clash TUN 时可能透明截获 Node2Socks Core 到上游节点的连接，必须提供检测和“绑定物理网卡/绕过建议”能力，详见 `06_CLASH_COEXISTENCE.md`。

## 5. 非目标（v1 不做）

- 不接管 Windows 全局代理。
- 不做 TUN 作为主要产品模式。
- 不做复杂规则分流编辑器。
- 不做机场销售/订阅计费。
- 不做公网 SOCKS5 服务器。
- 不让云服务中转用户网络流量。
- AdsPower API 自动同步不是 v1 阻塞项；v1 手工复制/批量导入即可。

## 6. UI 页面

1. **首页**：Core、订阅、节点、Slot、云同步、Clash 检测摘要。
2. **订阅**：添加/编辑/刷新、刷新状态、节点数量、过期/错误。
3. **节点**：搜索/筛选、协议、延迟、出口 IP、来源、创建/绑定 Slot。
4. **代理槽位**：端口、当前节点、状态、复制、切换、重启、删除。
5. **云同步**：本地模式/云模式、服务器地址、账号、设备、最后同步、冲突。
6. **设置**：端口范围、Core、启动项、网络出口、Clash 共存、更新、日志。
7. **诊断**：Core 版本、Controller、端口占用、网卡、Clash/TUN 状态、脱敏日志。

## 7. 首次启动

```text
欢迎使用 Node2Socks

[仅本地使用]   [启用云同步]
```

选择云同步：

```text
云服务器地址: https://sync.example.com
[检测连接]

账号 / 密码
[登录] [注册]
```

首次云登录且本地已有数据时必须询问：合并、本地覆盖云端、云端覆盖本地。默认推荐“合并”，禁止无提示覆盖。
